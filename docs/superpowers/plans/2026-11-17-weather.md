# 날짜마다 날씨 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 날짜 탭마다 그날 날씨(예보, 예보 밖이면 작년 이맘때)를 작게 보여준다.

**Architecture:** 순수 함수(`src/lib/weather.ts`: 아이콘·위치 고르기·작년 날짜) → Open-Meteo 요청+폰 저장(`src/lib/weatherApi.ts`) → 훅(`src/hooks/useWeather.ts`)이 날짜별 날씨를 모아 `DayTabs`에 넘김.

**Tech Stack:** React 19 + TypeScript, Vitest + Testing Library, Open-Meteo(키 없음).

**Spec:** `docs/superpowers/specs/2026-11-17-weather-design.md`

## Global Constraints

- 탭 글: 예보 `{아이콘} {최고}°/{최저}°` + 비 확률 ≥ 40이면 ` ☔{N}%`; 과거 `작년 {아이콘} {최고}°/{최저}°` 또는 `재작년 …`. 기온 반올림 정수.
- 아이콘: 0 ☀️, 1 🌤, 2 ⛅, 3 ☁️, 45·48 🌫, 51–57·80–82 🌦, 61–67 🌧, 71–77·85–86 🌨, 95–99 ⛈, 그 외 ☁️.
- 읽는 글(aria-label 일부): 0 맑음, 1–2 구름 조금, 3 흐림, 45·48 안개, 51–57·80–82 소나기, 61–67 비, 71–77·85–86 눈, 95–99 뇌우 → `맑음 12도/4도`, 과거면 앞에 `작년 이맘때 `/`재작년 이맘때 `.
- 위치 반올림 소수점 1자리. 예보 3시간(10_800_000ms) 신선, 과거·지명은 계속. 실패 시 저장본(기간 지나도), 없으면 그 날 날씨 없음.
- 과거 날짜: 1년 전 같은 날(2/29 → 2/28). 그 날짜가 `오늘 − 5일`보다 늦으면 2년 전 + `재작년`.
- URL: 예보 `https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lng}&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max&timezone=auto&forecast_days=16`; 과거 `https://archive-api.open-meteo.com/v1/archive?latitude=…&longitude=…&start_date=…&end_date=…&daily=weather_code,temperature_2m_max,temperature_2m_min&timezone=auto`; 지명 `https://geocoding-api.open-meteo.com/v1/search?name={이름}&count=1&language=ko`.

## Review Focus

1. 예보 응답에 일부 날짜만 있음(16일 경계) → 있는 날은 예보, 없는 날은 과거 → Task 3 테스트.
2. 예보 값이 `null`(먼 날 비 확률 등) → 비 확률만 생략, 나머지 표시 → Task 2 테스트.
3. 과거 기록 요청이 미래 날짜를 포함 → 요청 범위는 과거 날짜만(1·2년 전) → Task 1 테스트.
4. 같은 위치를 여러 날이 공유 → 예보 1번, 과거 1번 → Task 3 테스트.
5. 오프라인 첫 실행(저장본 없음) → 탭은 그대로, 날씨만 없음, 에러 없음 → Task 3 테스트.

### Task 1: 순수 함수

**Files:** Create `src/lib/weather.ts`, Test `src/lib/weather.test.ts`

**Interfaces — Produces:**
- `interface DayWeather { code: number; max: number; min: number; rain: number | null }`
- `type Past = '작년' | '재작년'`
- `interface TabWeather extends DayWeather { past: Past | null }`
- `interface Loc { lat: number; lng: number }`
- `weatherIcon(code: number): string`, `weatherWord(code: number): string`
- `roundLoc(l: Loc): Loc` (소수점 1자리)
- `pastDate(day: string, today: string): { date: string; past: Past }`
- `dayLocations(days: string[], byDay: Record<string, Item[]>, fallback: Loc | null): Record<string, Loc>` — 그날 처음 나오는 장소 있는 일정, 없으면 fallback, 둘 다 없으면 그 날 빠짐. 반올림 적용.
- `weatherText(w: TabWeather): string`, `weatherSpeech(w: TabWeather): string`

- [ ] **Step 1: 실패하는 테스트** — 아이콘·읽는 글 표의 대표값(0, 2, 3, 45, 53, 63, 73, 95, 999); `roundLoc({lat: 34.6937, lng: 135.5023})` → `{34.7, 135.5}`; `pastDate('2027-01-12', '2026-11-17')` → `{ date: '2026-01-12', past: '작년' }`; `pastDate('2027-11-20', '2026-11-17')` → `{ '2025-11-20', '재작년' }`; `pastDate('2028-02-29', '2027-06-01')` → `{ '2027-02-28', '작년' }`; `dayLocations`: 첫 장소 없는 일정 건너뜀, 장소 없는 날은 fallback, fallback도 null이면 키 없음; `weatherText({code:0,max:12.4,min:3.6,rain:20,past:null})` → `☀️ 12°/4°`; rain 70 → `… ☔70%`; rain null → 생략; past '작년' → `작년 ⛅ 11°/3°`(과거엔 ☔ 없음); `weatherSpeech` → `맑음 12도/4도`, `작년 이맘때 구름 조금 11도/3도`.

### Task 2: Open-Meteo 요청 + 폰 저장

**Files:** Create `src/lib/weatherApi.ts`, Test `src/lib/weatherApi.test.ts`

**Interfaces:**
- Consumes: `DayWeather`, `Loc` (Task 1)
- Produces (모두 `opts: { fetcher?: typeof fetch; storage?: Storage; now?: number }`):
  - `getForecast(loc: Loc, opts?): Promise<Record<string, DayWeather>>` — 키 `wx:f:{lat},{lng}`
  - `getHistory(loc: Loc, start: string, end: string, opts?): Promise<Record<string, DayWeather>>` — 키 `wx:h:{lat},{lng}:{start}:{end}`, rain 항상 null
  - `geocode(name: string, opts?): Promise<Loc | null>` — 키 `wx:g:{name}`, 결과 없음도 저장
  - 실패·오프라인은 저장본, 없으면 `{}`/`null` (throw 안 함)

- [ ] **Step 1: 실패하는 테스트** — 예보 URL이 Global Constraints와 같음; daily 배열 → 날짜별 객체(값 `null`인 날짜는 기온이 null이면 빠지고, 비 확률만 null이면 `rain: null`); 3시간 안엔 다시 안 부름, 지나면 다시; 실패 시 기간 지난 저장본; 저장본 없고 실패 → `{}`; 과거 URL·rain null·한 번 받으면 다시 안 부름; 지명 `오사카` → `{ lat, lng }` 반올림 안 함(호출 쪽에서), 결과 없음 → null 저장 후 다시 안 부름.
