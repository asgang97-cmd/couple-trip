# 예약·QR·바우처 보관함 (설계)

## 의도
예약 확인서·QR·바우처를 한곳에. 올리기만 하면 날짜/일정에 붙고, 비행기·해외 지하에서도 오프라인으로 열림.

## 방식 (사용자 선택: B)
- A 일정에서 올리기만 / **B A + PDF 글자에서 예약번호·날짜 찾아 추천 ✅** / C AI로 읽기(유료·외부 전송)

## 동작 (사용자 승인)
- 보관함 탭(날짜별, "날짜 없음"), 일정 카드의 바우처(그 일정에 바로 연결, 개수 표시).
- 올리기: 사진(JPG/PNG/HEIC)·PDF, 10MB까지. PDF는 글자에서 일정 예약번호 → 그 일정, 아니면 여행 기간 안 날짜 → 그 날을 미리 골라 둠. 사진은 직접 고름. 제목 = 파일 이름(수정 가능).
- 저장: Supabase 비공개 버킷 `vouchers` + 표 `vouchers`. PDF는 페이지 그림(최대 5쪽, JPEG)도 함께.
- 오프라인: 온라인일 때 모든 바우처를 기기 Cache Storage에 미리 받아 둠. "폰에 저장됨" 표시. 보기는 저장본 우선.
- 보기: 화면 가득, 흰 바탕(QR). PDF는 페이지 그림, 원본 열기.
- 수정: 일정·날짜·이름 바꾸기, 지우기(확인). 오프라인은 보기만.

## 빌더 재량
- pdf.js는 올릴 때만 불러옴(지연 로딩). 보기에는 필요 없음(페이지 그림).
- 사진은 긴 변 2000px JPEG(0.9)로 줄여 저장(QR 선명도 유지, 용량 절약). HEIC는 브라우저가 열 수 있을 때만.
- 날짜 인식: 2027-01-10 / 2027.1.10 / 2027/01/10 / 2027년 1월 10일 / 2027年1月10日 / 10 Jan 2027 / Jan 10, 2027.
- 예약번호 비교: 대소문자·공백·하이픈 무시, 3자 이상만.
