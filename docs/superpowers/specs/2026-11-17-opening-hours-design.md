# 영업시간·휴무일 경고 — 설계 (짧은 버전)

## 왜
여행 가서 "왔는데 문 닫았네 / 곧 마감이네"를 피하려고. 일정 카드에서 미리 알려준다.

## 목표 / 하지 않을 것
- 목표: 장소 검색으로 넣은 일정(`google_place_id` 있음) 카드에 문제가 있을 때만 경고 한 줄.
- 하지 않음: 이름만 적은 일정 확인, 영업시간 전체 표시, 지도 탭 변경, 데이터베이스 변경(SQL 없음).
- 실패로 볼 것: 확실하지 않은데 경고(헛경고). 정보가 없거나 못 받았으면 조용히 넘어간다.

## 정한 것 (사용자)
- 경고 범위 **B**: 그날 휴무 / 일정 시각에 아직 안 염 / 일정 시각에 이미 닫음 / 도착 후 **1시간 안에** 닫음.
- 받는 방법 **A**: 목록을 열 때 구글에 물어보고 폰(localStorage)에 **3일** 저장. 오프라인이면 저장본(기간 지나도) 사용.

## 고려한 방법
- A 볼 때 묻고 폰에 저장(선택): SQL 없음, 기존 일정 바로 적용, 7일 안쪽 특별 영업일 반영. 두 폰이 각자 물어봄.
- B 장소 고를 때 일정에 저장: 요청 최소, 두 폰 공유. 기존 일정은 다시 골라야 하고 바뀐 영업시간·임시 휴업을 모름.

## 모습 (문구 확정)
- `⚠️ 이날 휴무 (월요일)`
- `⚠️ 11:00엔 아직 안 열어요 (12:00 오픈)`
- `⚠️ 11:00엔 문 닫아요 (10:00 마감)` (그날 영업이 이미 끝났을 때. 다음 오픈 시각이 그날 뒤에 있으면 "아직 안 열어요"를 씀)
- `⚠️ 21:00 마감 · 30분 남아요`

## 동작 (내가 정한 부분)
- 시간 미정 일정: 그날 휴무인지만.
- 정보: Places API (New) Place Details `GET https://places.googleapis.com/v1/places/{id}`, 필드 `regularOpeningHours,currentOpeningHours`, 키는 기존 `VITE_GOOGLE_MAPS_API_KEY`.
- 일정 날짜가 여행지 시간대 기준 오늘~7일 안이면 `currentOpeningHours`(특별 영업일 반영) 우선, 아니면 `regularOpeningHours`의 같은 요일.
- 새벽까지 영업(마감이 다음 날 02:00 등)도 계산. 24시간 영업이면 경고 없음. 하루에 영업 구간이 여러 개(점심·저녁)여도 계산.
- 영업시간 정보가 없는 장소, 받기 실패 → 경고 없음.

## 만드는 사람에게 남긴 것
- 경고 줄 스타일(빠듯한 일정 경고와 같은 느낌, 기존 토큰), 키에 Places API (New) 권한이 없을 때 사용자 안내(한 번 확인).
