# 여행 설정 화면 (짧은 설계)

## 의도
여행 기간이 처음 넣은 5일(2027-01-10~14)로 고정돼 있고, 바꾸려면 Supabase Table Editor를 써야 함.
앱 안에서 둘이 직접 여행 정보를 바꿀 수 있게 한다.

## 목표 / 비목표
- 목표: 앱에서 **여행 이름, 여행지, 시작일, 마지막 날** 수정.
- 비목표: 통화·환율·시간대 수정(계속 Supabase에서), 여행 여러 개, 일정 일괄 이동.
- 안티목표: 기간을 줄였다고 일정이 지워지는 것.

## 방식 (고른 것: A)
- **A. 커버의 ⚙️ 버튼 → 바텀시트 설정 창** — 일정 추가 창과 같은 모양, 네 칸을 한곳에. ✅ 사용자 선택
- B. 제목을 눌러 바로 편집 — 날짜·여행지를 넣을 자리가 없어 결국 창이 또 필요.

## 동작
- 커버 오른쪽 위 📷 옆에 ⚙️. 오프라인이면 막힘.
- 칸: 여행 이름(필수, 1~100자), 여행지(선택, 100자), 시작일·마지막 날(date 입력).
- 마지막 날 < 시작일이면 안내 문구 + 저장 막음. 기간 "N일 여행" 표시.
- 기존 일정 중 새 기간 밖으로 밀려날 개수를 미리 경고("숨겨져요, 지워지진 않아요"). 저장은 가능.
- 저장 → `trips` update(id 조건) → 다시 불러오기. 실시간으로 상대 화면에도 반영(기존 구독).
- 실패 시 알림, 입력 유지.

## 빌더 재량 (내 판단)
- 기간 최대 길이 제한은 두지 않음(날짜 탭이 가로 스크롤).
- 선택된 날짜 탭이 새 기간 밖이면 기본 선택(오늘/첫날)으로 돌아감.
- DB 검사: `end_date >= start_date` 제약 추가 마이그레이션(004)은 선택 — 앱 검사로 충분, 추가 시 재실행 가능하게.
