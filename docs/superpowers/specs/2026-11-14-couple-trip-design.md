# 둘만의 여행 앱 — 설계 (Spec)

날짜: 2026-11-14 · grill-me 세션에서 정함

## 목적
- 여자친구에게 주는 **선물**. 기능 완성도보다 "나를 위해 만들었구나" 감성이 우선.
- 마감: 1~3달 안(다가오는 해외여행 전).
- 개발: 뼈대는 Claude와 같이(설명 들으며), 테마·문구·사진은 직접 채운다.

## 형태 · 기술
- PWA 웹앱 (홈화면 설치). 앱스토어 없음.
- React(Vite, TypeScript) + Supabase(DB·인증·실시간) + Vercel(배포). 모두 무료 티어.
- 로그인: 둘만 아는 **공유 비밀번호** 하나. 처음 한 번 "누구세요? 🧑/👩" 선택 → 기기에 기억, 작성자 표시에 사용.

## 핵심: 일정 같이 짜기
- 각자 폰에서 추가·수정·삭제 → 상대 폰에 반영 (새로고침 없이 반영되면 좋지만 동시편집 수준은 불필요).
- 일정 항목 = 날짜, 시간(선택), 장소명, 메모, 예약 확인번호, 예약 링크, 예상 비용, 지도 위치.
- 예약 정보는 **텍스트만** (첨부파일 없음).
- 비용: **현지통화 입력 + 원화 환산 표시**, 합계는 원화. 환율은 **실시간 자동**.
  - 시간이 없으면 가장 먼저 빼는 기능: 실시간 환율 → 수동 입력으로 대체.
- 지도: **구글맵**으로 하루 일정 핀 + 동선 + 장소 검색. (해외 위주라 구글맵)
- 오프라인: 마지막으로 불러온 일정은 **보기 가능**, 수정은 온라인에서만.

## 감성 요소
- D-day 카운트다운 (첫 화면)
- 둘만의 테마 색 · 커플 사진
- 일정 항목에 하트(❤️) · 댓글

## 범위
- 화면은 **여행 하나**만. 단, 데이터는 처음부터 `trip` 단위로 저장해 나중에 여러 여행 목록으로 확장 가능하게.

## 알려진 위험
- 구글맵 API는 카드 등록 필요 → 키에 도메인 제한 + 일일 할당량 상한 + 예산 알림 필수.
- 공유 비밀번호 방식은 보안이 약함 → 여권번호 등 민감정보 저장 금지.
