# 커버 사진 자르기 (짧은 설계)

## 의도
커버 사진을 원하는 부분·크기로 잘라 넣기. 큰 사진은 확대해 일부만, 작은 사진은 확대해서.

## 동작 (사용자 승인)
- 📷로 고르면 바로 올리지 않고 자르기 바텀시트.
- 4:3 틀(폰 커버 모양), 틀 밖은 어둡게. 끌어서 위치, 두 손가락·크기 막대로 확대(1~4배). 가장 작게 해도 틀은 사진으로 꽉 참(여백 없음).
- 저장 = 틀 안 그대로 1200×900 JPEG로 잘라 올림. 취소 = 변화 없음.
- 새 라이브러리 없음.

## 빌더 재량
- 키보드: 틀에 초점 → 화살표 이동, +/- 확대.
- 확대 기준점: 두 손가락 가운데 / 막대는 틀 가운데.
- 수학(가리기·확대·잘라낼 영역)은 `lib/crop.ts` 순수 함수로 테스트.
