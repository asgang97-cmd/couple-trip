# 비짓재팬(VJW) 준비 (짧은 설계)

## 의도
밍석이 둘(밍석·밍하) 다 Visit Japan Web에 등록한다. 여행 전에 앱에 입력해 두고, 칸마다 복사 버튼으로 VJW에 붙여넣어 빠르게 끝내기.

## 목표 / 비목표
- 목표: 두 사람의 여권·입국·일본 주소 정보를 **이 폰에만** 저장하고, 칸별 복사.
- 비목표: 서버 저장·공유, VJW 자동 입력, 세관 질문(예/아니오).
- 안티목표: 여권 정보가 서버(Supabase)나 상대 폰으로 가는 것.

## 방식
- A. 기기(localStorage)에만 저장 ✅ 사용자 선택 (둘 다 밍석 폰에서 등록)
- B. Supabase 저장·공유 — 공유 비밀번호가 새면 여권 정보 노출.

## 동작
- 커버의 비행기 버튼 → "비짓재팬 준비" 바텀시트. 오프라인에서도 열림.
- 사람 선택(밍석/밍하) → 묶음 3개: 여권(여권번호, 성, 이름, 국적, 생년월일, 성별, 여권 만료일) · 입국(방문 목적, 체류 기간, 항공편명, 도착 날짜, 도착 공항) · 일본 내 주소(숙소 이름, 우편번호, 주소, 전화번호) + 자유 메모.
- 보기 모드: 값 + 복사 버튼, "복사했어요" 잠깐. 여권번호는 앞 4자리만 보이고 나머지 가림, 복사는 전체.
- 수정 모드: 입력칸, 저장.
- 상대 사람 화면에서 "밍석과 같게": 입국·주소 묶음을 복사.
- 일정에서 가져오기: 항공편명 ← 예약번호가 있는 일정 중 선택, 숙소 이름 ← 일정 장소 중 선택, 도착 날짜 기본값 = 여행 시작일.
- "이 폰에서 지우기"(확인 후 전부 삭제).

## 빌더 재량 (내 판단)
- 저장 키 `vjw:v1`, 값 검증 없이 문자열 저장(형식은 VJW가 검사).
- 기본값: 국적 "대한민국(KOR)", 방문 목적 "관광", 도착 공항 미입력.
- 체류 기간 기본값 = 여행 일수.
